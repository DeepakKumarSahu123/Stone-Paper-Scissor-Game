# Rock Paper Scissors Game

A simple browser game where you play Rock, Paper, Scissors against the computer. Built with HTML, CSS and vanilla JavaScript.

## Features

- Click Rock, Paper or Scissors to make your move
- The computer picks a random move each round
- Live score board for you and the computer
- Result message after every round (win, lose or draw), color-coded:
  - Green for a win
  - Red for a loss
  - Dark blue for a draw
- Hover effect on the choice buttons

## How to Play

1. Open the game in your browser.
2. Click one of the three images: **Rock**, **Paper** or **Scissors**.
3. The computer makes its choice automatically.
4. The winner is shown in the message box and the score updates.

### Rules

| Your move | Beats    |
| --------- | -------- |
| Rock      | Scissors |
| Paper     | Rock     |
| Scissors  | Paper    |

If both players choose the same move, the round is a draw.
